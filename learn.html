Learn CSS: One Stylesheet, Every Day

My study planner has a page for every day of the week, and they all look the same because they share one stylesheet. This tool teaches how that works: the <head>, the <link> line, and the cascade (which rule wins). Go in order: learn it, try it, get quizzed.

How one file styles every page

Head vs body

Every page has two parts. The <body> holds everything you can see. The <head> holds information about the page that you don't see on it: the <title> (the words on the browser tab) and the line that loads the stylesheet.

<head>
  <title>Monday</title>                         ← shows on the tab
  <link rel="stylesheet" href="planner.css">   ← loads the styles
</head>
<body>
  <h4>Monday</h4>                              ← shows on the page
</body>

The link line

<link rel="stylesheet" href="planner.css"> tells the browser "go get planner.css and use its rules on this page." rel="stylesheet" says what kind of file it is, and href is the path to it. The path has to match the file name exactly, or the page loads with no styles and no error message.

Put that same line in the head of all four pages and they all use the same rules. Change a rule once in planner.css, and all four pages change.

Rules and selectors

.acct { background: #D9822B; }
 ↑        ↑            ↑
 selector property     value
  • h4 picks every <h4> tag.
  • .acct, with a dot, picks every tag with class="acct". In the HTML you leave the dot off.
  • #today, with a #, picks the one tag with id="today".

The cascade: which rule wins

When two rules set the same thing on the same tag:

  1. The more specific selector wins. An id beats a class, and a class beats a plain tag name, no matter which rule comes first.
  2. If they're equally specific, the one that comes later wins. Two .phil rules? The lower one in the file wins.

A misspelled property or value, like backgroud, is skipped without any error. The rest of the rules still work.
