How this page works: one stylesheet, every class color

Every ACCT 261 block on this map, in the list and in the editor gets its color from one rule in tools.css: .c-acct { background: #D9822B; }. The blocks just carry class="c-acct". Change that one rule and every ACCT block on the page changes. That's the same reason one styles.css can brand all my pages. Try it in Learn CSS →

How this page works: labels and inputs

Each box is an <input> with a <label for="…"> whose for matches the input's id. Click a label and the cursor jumps into its box. It's the same idea as a link's href pointing at a file: one name has to match another exactly.

How this page works: head vs body

Everything you can see is inside <body>. The <head> holds things you don't see on the page: the <title> ("Goomba Grails | Study Planner", shown on the browser tab) and the two <link> lines that load styles.css and tools.css.
